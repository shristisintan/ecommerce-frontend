# NOVA Ecommerce Frontend

NOVA is a responsive multi-store ecommerce marketplace built with React, TypeScript, Vite, and Tailwind CSS.

The application supports three user roles:

- Buyer
- Merchant
- Admin

The frontend communicates with the NOVA Express/MongoDB backend through REST APIs.

---

## Features

### Buyer

- Buyer registration and login
- Browse products from multiple merchants
- Search products
- Category filtering
- Price filtering
- Product sorting
- Product details
- Shopping cart
- Multi-step checkout
- Zod form validation
- Checkout data persistence using localStorage
- eSewa payment flow
- View order history

### Merchant

- Merchant registration
- Multi-tenant store account
- Merchant dashboard
- Product management
- Add products
- Edit products
- Activate/deactivate products
- Product search
- Category filtering
- Product pagination
- View merchant-specific orders
- Order status filtering
- Payment status filtering
- Order pagination

### Admin

- Admin dashboard
- Category management
- Add categories
- Edit categories
- Activate/deactivate categories
- Search categories
- Category pagination
